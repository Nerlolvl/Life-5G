# Life 5G · life:) Беларусь на iPhone

Включает **5G**, **VoLTE + EVS (HD Voice+)** и **звонки по Wi-Fi** на iPhone с SIM/eSIM **life:) (Беларусь, 257-04)**.

Основа: [CarrierSIM](https://github.com/ios-bundles/CarrierSIM) (MIT, автор Vladimir B / vlw). Код CarrierSIM не изменён — добавлена только конфигурация и обёртка-установщик.

**Как это работает.** iOS выбирает пакет настроек оператора по IMSI. Скрипт кладёт в пользовательский каталог пакетов симлинк с именем вашего IMSI (15 цифр) на подписанный Apple пакет из прошивки. Родной пакет Беларуси `life_by` **скрывает 5G и отключает EVS** — поэтому ставится пакет «Life» (`Turkcell_lifecell_ua`, lifecell Украина): 5G ✅ EVS ✅ VoLTE ✅. SIM и сеть остаются life:) — меняется только поведение телефона. Частоты 5G задаёт прошивка (GRI), пакеты на них не влияют.

## Состав адаптации

| Файл | Что делает |
|---|---|
| `bundle.yaml` | Пакеты для операторов: все белорусские SIM → «Life» (`Turkcell_lifecell_ua`) |
| `life5g.py` + `Life5G.cmd` | Установщик с перебором: «Life» → `Vodafone_hu` → `O2_Germany` (первый подтверждённый iOS остаётся) |
| `README-CarrierSIM.md` | Полная документация оригинала (меню 1–11, диагностика, сбои) |

Проверено: iOS **27.0.1** (iPhone 12, eSIM life:)) — профиль подтверждён iOS. Работает на iOS 16–27.2 beta 2, физ. SIM и eSIM одинаково (привязка по IMSI). **iOS 27.2 beta 3+ — не поддерживается** (Apple закрыла способ записи).

## Требования

- iPhone 12–18 (5G — iPhone 12 и новее)
- Windows: **Python 3.11+ x64** ([python.org](https://www.python.org/downloads/windows/)) и **iTunes x64** ([инструкция 4PDA](https://4pda.to/forum/index.php?showtopic=554020&st=3760#entry107393362)); macOS/Linux — ничего дополнительно
- Кабель USB

## Установка (5 минут)

1. Распакуйте папку целиком (не из архива — в «Загрузки» или «Документы»).
2. iPhone: **Настройки → Экран и яркость → Автоблокировка → Никогда** (вернуть после).
3. Подключите кабелем, разблокируйте, нажмите «**Доверять**». Закройте iTunes/Finder.
4. Запустите **`Life5G.cmd`** (Windows) / `Запуск macOS.command` / `bash "Запуск Linux.sh"` → в меню **1**.
   - Первый запуск сам поставит зависимости в `.venv` (пара минут, нужен интернет).
   - Держите телефон разблокированным с включённым экраном до «Готово».
5. Ждите: **«SIM 2 (25704): Turkcell_lifecell_ua — подпись принята» → «Готово»**.

Сбой или обрыв связи? Запустите пункт **5** (восстановление), затем повторите пункт **1**.

## После установки

1. **Перезагрузите iPhone.**
2. **APN** (иначе не будет интернета): Настройки → Сотовая связь → life:) → Сотовая сеть передачи данных → **APN: `internet.life.com.by`** → вкл/выкл авиарежим.
3. **5G**: Настройки → Сотовая связь → Параметры данных → Голос и данные → **5G вкл**; Режим данных → «Разрешить больше данных в 5G».
4. Проверка: наберите `*3001#12345#*` → **n-полосы** (n78 = 3,4–3,8 ГГц) = 5G; только **b-полосы** = вы в LTE (вне зоны 5G life:)).
5. ❌ Предложение «**Обновить настройки оператора**» — **отклоняйте**: сбрасывает профиль (вернуть — запустить установку заново).
6. Верните автоблокировку.

## Частые вопросы

**Профиль слетел?** Привязан к IMSI: перевыпуск SIM/eSIM или перенос номера = новый IMSI → запустите `Life5G.cmd` снова. Обновление iOS профиль сохраняет, но ставить новый на iOS 27.2 beta 3+ уже нельзя.

**Значок 5G есть, скорости нет.** Значок ≠ 5G: смотрите n-полосы в Field Test. life:) 5G — пилотные зоны (Минск и др.), вне зоны LTE.

**Звонки по Wi-Fi?** Пакет VoWiFi включает на стороне телефона (приоритет Wi-Fi, подпись «lifecell VoWiFi»), но нужен ePDG-сервер на стороне life:) — если его нет, VoWiFi не подключится ни с каким пакетом.

**Какой пакет выбрать?** «Life» — 5G + EVS + переключатель VoLTE и приоритет Wi-Fi для звонков; `Vodafone_hu` — «Авто 5G» и XCAP, но значок 4G и VoLTE без переключателя; `O2_Germany` — 5G SA и VoNR. Порядок попыток меняется в начале `life5g.py`.

**Откат:** меню **4** (`py carrier.py --restore`) — вернуть штатный профиль; **5** — восстановление после сбоя.
