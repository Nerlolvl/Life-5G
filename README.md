# Life 5G · life:) Беларусь на iPhone

Включает **5G**, **VoLTE + EVS (HD Voice+)** и **звонки по Wi-Fi** на iPhone с SIM/eSIM **life:) (Беларусь, 257-04)**.

Основа: [CarrierSIM](https://github.com/ios-bundles/CarrierSIM) (MIT, автор Vladimir B / vlw). Код CarrierSIM не изменён — добавлена только конфигурация и обёртка-установщик.

**Как это работает.** iOS выбирает пакет настроек оператора по IMSI. Скрипт кладёт в пользовательский каталог пакетов симлинк с именем вашего IMSI (15 цифр) на подписанный Apple пакет из прошивки. Родной пакет Беларуси `life_by` **скрывает 5G и отключает EVS** — поэтому ставится пакет «Life» (`Turkcell_lifecell_ua`, lifecell Украина): 5G ✅ EVS ✅ VoLTE ✅. SIM и сеть остаются life:) — меняется только поведение телефона. Частоты 5G задаёт прошивка (GRI), пакеты на них не влияют.

## Совместимость

| Что | Поддерживается |
|---|---|
| iPhone | 12–18 (5G — iPhone 12 и новее), включая mini/Pro/Pro Max/Plus/Air/e |
| iOS | 16 – 27.2 beta 2 |
| iOS 27.2 beta 3 и новее | ❌ Apple закрыла способ записи — скрипт остановится сам |
| SIM | Физическая nano-SIM и eSIM — одинаково (привязка по IMSI) |
| Компьютер | Windows x64, macOS (Intel/Apple Silicon), Linux x64 |

## Состав адаптации

| Файл | Что делает |
|---|---|
| `bundle.yaml` | Пакеты для операторов: все белорусские SIM → «Life» (`Turkcell_lifecell_ua`) |
| `life5g.py` + `Life5G.cmd` | Установщик: ставит «Life»-пакет, при невозможности сам откатывает изменения |
| `README-CarrierSIM.md` | Ссылки на оригинальный проект и его документацию |

## Установка — пошагово

### Шаг 1. Подготовка компьютера

**Windows:**

1. Установите **Python 3.11 или новее (x64)**: [python.org/downloads/windows](https://www.python.org/downloads/windows/). При установке отметьте «Add python.exe to PATH».
2. Установите **iTunes x64 (классический установщик)**: [инструкция на 4PDA](https://4pda.to/forum/index.php?showtopic=554020&st=3760#entry107393362). Версия из **Microsoft Store** и приложение **Apple Devices не подходят** — скрипту нужны библиотеки Apple (AirTrafficHost, CoreFoundation, MobileDevice) из полного установщика. После установки перезагрузите компьютер.
3. Если iPhone виден в Проводнике, но не находится скриптом — установите драйвер «Apple Mobile Device USB Driver» из [Microsoft Update Catalog](https://www.catalog.update.microsoft.com/Search.aspx?q=Apple%20Mobile%20Device%20USB%20Driver) и выполните в командной строке от администратора: `pnputil /add-driver usbaapl64.inf /install`.

**macOS / Linux:** ничего дополнительно. На Linux — `sudo apt install usbmuxd` (Debian/Ubuntu).

### Шаг 2. Подготовка iPhone

1. Скачайте репозиторий (**Code → Download ZIP**) и **распакуйте папку целиком** в «Загрузки» или «Документы».
2. На iPhone: **Настройки → Экран и яркость → Автоблокировка → Никогда** (после установки верните как было). Экран не должен гаснуть во время записи.
3. Подключите iPhone **кабелем** к компьютеру, разблокируйте и нажмите «**Доверять этому компьютеру**» (введите код-пароль).
4. Закройте iTunes и Finder, если открыты.

### Шаг 3. Установка профиля

1. Запустите:
   - **Windows:** двойной щелчок `Life5G.cmd`
   - **macOS:** `Запуск macOS.command`
   - **Linux:** `bash "Запуск Linux.sh"`
2. В меню выберите **1** — установка по `bundle.yaml`.
3. Первый запуск сам скачает зависимости в `.venv` (2–3 минуты, нужен интернет). Дальше начнётся установка.
4. **Держите iPhone разблокированным с включённым экраном** до самого конца (иногда касайтесь экрана, чтобы он не погас — погасший экран обрывает связь).
5. Вы увидите план: `сейчас: life_by → план: Turkcell_lifecell_ua (по IMSI)`, затем этапы 1–4. Готово — когда появится:

   ```
   SIM … (25704): Turkcell_lifecell_ua — подпись принята
   Готово.
   ```

Вся установка занимает **2–5 минут**. Если пакет не подтвердится, скрипт сам вернёт телефону прежнее состояние — ничего не сломается, можно просто повторить запуск.

### Шаг 4. Если что-то пошло не так

| Проблема | Решение |
|---|---|
| «Сбой во время записи», обрыв связи | В меню выберите **5** («Восстановить после сбоя»), затем повторите **1** |
| «Разблокируйте iPhone…» долго висит | Разблокируйте телефон, переподключите кабель, проверьте «Доверять» |
| «Не найден Python» / «AirTraffic backend недоступен» | Не установлен Python 3.11+ x64 или iTunes x64 — см. Шаг 1 |
| «iPhone не виден» | Другой кабель/порт USB (без хабов), переустановить драйвер (Шаг 1), перезапустить службу «Apple Mobile Device Service» |
| Выбранный пакет не подтверждён | Ничего делать не нужно — скрипт сам откатил настройки; запустите установку ещё раз |

Папка `runs` хранит копии и журналы операций — не удаляйте её до успешной установки и не публикуйте (внутри идентификаторы SIM).

### Шаг 5. После установки

1. **Перезагрузите iPhone.**
2. **Впишите APN life:)** — иначе не будет мобильного интернета:
   **Настройки → Сотовая связь → life:) → Сотовая сеть передачи данных** → APN: `internet.life.com.by` (MMS-настройки возьмите из приложения/на сайте life:)), затем вкл/выкл авиарежим.
3. **Включите 5G:** Настройки → Сотовая связь → Параметры данных → Голос и данные → **5G вкл**; Режим данных → **«Разрешить больше данных в 5G»**.
4. **Проверьте 5G:** наберите `*3001#12345#*` → вызов. Полосы с буквой **n** (например n78 = 3,4–3,8 ГГц) — 5G; только **b-полосы** — вы в LTE (вне зоны покрытия 5G life:)).
5. ❌ Если появится предложение «**Обновить настройки оператора**» — **отклоните**: оно сбрасывает профиль (вернуть — повторить Шаг 3).
6. Верните автоблокировку: Настройки → Экран и яркость.

## Откат

- Вернуть штатный профиль: меню **4** (или `py carrier.py --restore`).
- Восстановление после сбоя: меню **5** (`py carrier.py --recover`).
- Полный сброс iPhone также снимает профиль.

## Частые вопросы

**Профиль слетел?** Он привязан к IMSI: перевыпуск SIM/eSIM или перенос номера = новый IMSI → повторите Шаг 3. Обновление iOS профиль сохраняет, но поставить новый на iOS 27.2 beta 3+ уже нельзя.

**Значок 5G есть, скорости нет.** Значок ≠ 5G: смотрите n-полосы в Field Test (`*3001#12345#*`). Сеть 5G life:) работает в пилотных зонах (Минск и др.), вне зоны — LTE.

**Звонки по Wi-Fi?** Пакет включает VoWiFi на стороне телефона (приоритет Wi-Fi, подпись «lifecell VoWiFi»): Настройки → Сотовая связь → life:) → Вызовы по Wi-Fi. Для работы нужен ePDG-сервер на стороне life:) — если его нет, VoWiFi не подключится ни с каким пакетом.

**EVS не включается?** EVS работает, только если он есть у обоих абонентов и оба в IMS. Проверяйте звонком абоненту того же оператора, не на короткие номера.

**Какой пакет используется?** Один — «Life» (`Turkcell_lifecell_ua`): переключатель 5G, EVS, VoLTE и приоритет Wi-Fi для звонков. Каталог всех пакетов iOS: [ios-bundles.github.io](https://ios-bundles.github.io); сменить — строка `25704` в `bundle.yaml` и список `BUNDLES` в `life5g.py`.
